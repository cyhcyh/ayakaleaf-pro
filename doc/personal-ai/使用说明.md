# 本地体验

打开 http://localhost:8080，继续使用原来的账户与项目。

## 模型连接

编辑器左下角「设置」→「AI 与翻译」。助手标题旁的齿轮也能打开此页。

1. 在「模型连接」添加 OpenAI 兼容接口，填写 Base URL 和 API Key，获取模型或手动填写模型 ID，并测试连接。「获取可用模型」和「测试连接」会保存该连接，不要求先填完其他功能分配。已获取的模型目录会保留，可搜索选择。
2. 使用 Codex 时，添加 Codex 连接，按页面显示的设备码到 ChatGPT 授权，再获取模型。账号需要具备相应模型权限。
3. 在列表式的「功能分配」中分别选择 AI 助手、编译错误修复、论文审阅、大模型翻译的连接、模型、思考模式和推理强度。参数按模型实际支持情况提供。未独立分配的功能沿用助手完整配置。站点有服务器配置时才显示站点预设。

设置属于当前用户。服务端加密保存密钥，页面只显示是否已保存。更换服务地址时需要重新填写密钥。

发送按钮左侧的大脑图标可选择当前会话的连接、模型和推理强度，点击「完成」后生效。该选择随会话保存，不改变功能分配。点击「沿用默认」恢复设置中的分配，新会话默认沿用全局设置。生成回复或执行工具时暂不能切换模型。

## 划词翻译

在 PDF 的文字层或 LaTeX 编辑区划选词句，选区末尾会出现一个小绿点。悬停约 250 毫秒打开气泡，也可以点击小绿点。圆点保持原来的选区末端位置，显示层级高于「添加评论」浮层。

气泡上方选择翻译服务，下方选择目标语言。气泡内原文默认两行，可以展开。气泡保持在窗口内，长内容在内部滚动，标题和关闭按钮始终可见。支持复制、固定和关闭，Esc 也可关闭。

原文标题旁的小箭头用于展开/收起。原文和译文均支持数学公式显示。识别到的 TeX 公式在翻译期间会保留，复制时仍是 TeX 源文。

默认支持 Google 免 Key 和 MyMemory。后者有匿名额度和约 500 字节的单次限制，自动识别针对中英文场景。大模型翻译使用「功能分配」中指定的模型。Google Cloud 官方接口需要单独添加连接。免费服务的可用性受网络和服务额度影响。

## 论文审阅与参考资料

直接对 AI assistant 说明任务，例如：

> 请审阅 main.tex 的引言与定理证明，重点检查假设是否充分。结合我上传的 PDF，以及项目内的 references.bib 和这个网页链接，先说明审阅范围，再把具体问题添加为评论。

助手可以列出项目文件与已上传参考资料、读取 PDF/文本、检索公开文献、打开网页及公开 PDF。附件入口支持 PDF、TXT、Markdown（每个小于 8 MB）和原有图片。扫描 PDF 第一版不提供 OCR。

正式审阅前，助手会给出范围和重点，并询问是否允许写入评论。点击「同意审阅并添加评论」，或者在待确认时明确回复「同意」，才开始本轮审阅。意见写入原生审阅面板，以「[AI 审阅]」标识，可以继续回复或解决。停止按钮会撤销本轮授权。已写入的评论保留。

## 修改论文与撤销

向助手说明修改要求。助手提出修改后，正文仍保持原样，代码编辑区标出相关位置。点击标记、左侧「AI 修改」或对话中的「查看 AI 修改」，打开编辑区旁的窄栏。卡片与对应源文行联动，点击「查看差异」展开增删内容。当前文件按行排列，也可切到全部文件查看其他记录。

「AI 修改」和「审阅」各有独立入口，使用相同栏位，打开一个时收起另一个。原生评论、修订和 AI 修改记录分别保留。

逐项「接受」或「拒绝」。已接受的建议可在「已处理」中「撤销」，随后还可「重新应用」。刷新页面、切换会话或删除会话后，修改记录仍保留。若正文已有冲突修改，系统会停止并提示重新核对。请重新生成建议。

操作中断时可用「核对上次操作」确认服务器正文状态，不会自动重放源文修改。模型给出的建议仍需人工核对。

## 历史会话与上下文压缩

助手顶部齿轮左侧的历史按钮支持搜索标题和对话文字，结果显示命中片段。可切换、新建、重命名，也可多选或全选已显示会话后批量删除。空白草稿不计入历史。删除会话保留项目正文、评论和 AI 修改记录。刷新会恢复当前会话，上次未完成的工具不会自动执行。论文审阅需重新确认。

长会话先读取最近 20 个完整轮次，向上阅读时继续补载，并保持阅读位置。消息按可视区域渲染，公式、图片和工具记录仍可正常查看。模型上下文由服务端补齐，阅读时尚未加载的消息不会因此丢失。

「AI 与翻译 → 上下文压缩」沿用“外观”页的表单样式，可选择独立的压缩连接、模型和思考参数。默认开启，85% 触发、20% 摘要目标。高级设置显示当前采用的容量和摘要上限，也可手动修改。点击「自动」恢复自动取值。无法读取模型数据时，上下文容量按 256,000 tokens，摘要输出上限按 8,192 tokens。实际摘要还受目标比例和模型容量限制。

压缩按完整轮次保留工具调用和结果，并增量整理早期内容。完整聊天记录仍保存在历史中。上下文预算为估算值，摘要不携带旧审阅授权。

## 数据管理与项目删除

「AI 与翻译 → 数据管理」可清空当前项目或自己所有项目的历史会话，默认当前项目。清空前会弹窗确认。清空会删除对话和摘要，保留正文、评论、参考文件、模型连接和 AI 修改记录。

移入回收站或处于可恢复删除阶段时，AI 记录和参考附件随项目保留。项目到期彻底清理时，会话、消息、摘要、活动会话指针、审阅授权、AI 修改记录和参考附件会一起删除。清理过程兼容旧版附件路径，并阻止延迟请求重建记录。

## 更新与维护

开发分支为 `feature/personal-ai-translation-review`。`origin` 是你的 fork，`upstream` 是原 Ayakaleaf 项目，`overleaf` 是 Overleaf 原项目。优先合并 Ayakaleaf 上游，由其继承 Overleaf 更新。

构建与合并接入点见 [README](README.md)。保持 `.env` 中的会话密钥或独立加密密钥不变，以便读取已保存的模型凭据。不要提交 `.env`。
